# Демо-сайты для портфолио

Вёрстка без фреймворков: HTML, CSS, чистый JavaScript. Адаптив под телефон, планшет и компьютер.

| Сайт | Что показывает |
|---|---|
| [PriceRadar](priceradar/) — лендинг SaaS-сервиса для селлеров WB | тёмная тема, макет дашборда на SVG, переключатель тарифов «месяц / год», FAQ на `<details>`, появление блоков при прокрутке, мобильное меню |
| [AI Days 2026](aidays/) — сайт конференции | светлая тема и крупная типографика, таймер обратного отсчёта, вкладки программы, бегущая строка, карточки спикеров и билетов |

Конференция, сервис и спикеры вымышленные — это демо вёрстки.

## Запуск локально
```
python -m http.server 8765
```
и открыть http://localhost:8765/priceradar/ или /aidays/.
